## חזרה לגרסה קודמת (rollback)

גל 1 הוסיף `'failed'` ל-`tasks_kind_check` ואינדקס `tasks_open_failed_post_idx`. הסכימה הישנה
מוסיפה מחדש את האילוץ בלי `'failed'` ונכשלת בעלייה אם יש שורות כאלה. לפני rollback לגרסה
שלפני גל 1 מריצים בפרוד:

```sql
update tasks set kind = 'general' where kind = 'failed';
drop index if exists tasks_open_failed_post_idx;
```
